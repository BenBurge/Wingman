Wingman · phase 1 and 2 screens

Wingman TUI mockups

Seven screens at 96 columns, drawn in the default Midnight theme. Every table is the same widget: a filterable, sortable list on the left and a details pane on the right, with the tab strip and key bar fixed. Everything is operable by keyboard or mouse. Package data is illustrative.

1 · Installed

The default view on launch. Typing filters the list live, and the details pane follows the cursor and is fed by winget show in the background so the list never blocks.

  • Tabswitch pane
  • scycle sort column
  • uupgrade
  • xuninstall
  • ppin / unpin
  • oinstall options
  • bbundle export / import
  • 1‑5tabs






  
2 · Discover

  
Search runs against winget when you press Enter, not on every keystroke, because a search takes a second or two. Rows already on the machine carry a check mark so you don't install twice.

  

  
  • Entersearch
  • iinstall
  • vpick version
  • Spacemark for batch
  • Enter on a row: details






  
3 · Updates

  
The tab title carries the count so it works as a badge. Held packages stay visible but dimmed with a hold marker instead of vanishing. Marking rows builds the queue shown on the right before anything runs.

  

  
  • Spacemark
  • amark all
  • grun queue
  • phold / release
  • Vskip this version
  • rrefresh






  
4 · Running a batch

  
The content area becomes the runner. One UAC prompt happens up front when any queued operation needs elevation, then everything streams through. Each operation's log lands in History whether it succeeds or fails.

  

  
  • Esccancel remaining
  • ↑↓scroll log
  • Enterreturn to list when done






  
5 · Install options for one package

  
This is UniGetUI's InstallationOptions block as a form. What you set here is saved per package, reused on every future upgrade, and written into exported bundles unchanged.

  

  
  • Tabnext field
  • Spacetoggle
  • Entersave
  • Esccancel
  • Ctrl+Rreset to defaults






  
6 · History

  
One row per operation, newest first, with the full winget output for the selected row on the right. Failed operations can be retried from here with the same options.

  

  
  • Enteropen log
  • Rretry
  • /filter
  • Delforget






  
7 · Settings

  
Everything in settings.json, edited in place. The tools row at the bottom holds the scheduled-task registration, so nothing needs an installer. Bundle export and import also appear here, but their home is the b key on any package tab.

  

  
  • Tabnext field
  • Spacetoggle / pick
  • Enteractivate tool
  • Changes save immediately






  
8 · Export bundle

  
Reached with b from Installed, Discover, or Updates. Everything winget can reinstall is pre-checked. Packages winget only knows about but can't install, like things detected from Add/Remove Programs, are listed as skipped, which is how UniGetUI treats them too.

  

  
  • Spacetoggle
  • aall
  • nnone
  • monly marked rows
  • Enterwrite file
  • Esccancel






  
9 · Import bundle

  
Opens with a file picker, then shows a plan before anything runs. Each row says what will happen: install, upgrade, keep, or skip. Packages from other managers in a UniGetUI bundle are shown but can't be selected. Running the plan hands off to the batch runner from screen 4.

  

  
  • Spacetoggle
  • oview the bundle's options for a row
  • Enterrun plan
  • Esccancel

11 · Tray icon

  
Three candidates, each shown as the app tile at 64 and 32, then at tray size on a dark taskbar, with a badge, and on a light taskbar. The tray and toast mockups below use A.

  

    

      
A · W with a wing tip recommended

      

      
The W of Wingman whose last stroke lifts into a wing. Reads as a letter at 16 pixels and as a wing at 64, and it is unmistakable among the other monochrome tray glyphs.

    

    

      
B · Scalloped wing

      

      
A single wing silhouette with two notched feathers on the trailing edge. Handsome on the app tile, but at 16 pixels it collapses into a slanted leaf.

    

    

      
C · Chevron wing

      

      
Two heavy swept strokes. Bold at small sizes and trivial to reproduce, but it can read as a generic swoosh.

    

  


  
Iterations on A

  
Seven variations on the W. Each shows the app tile at 64 and 32, then the tray glyph on dark, with a badge, and on light.

  

    

      
A1 · Baseline

      

      
The version used across the page. Even 2-unit stroke, sharp valleys.

    

    

      
A2 · Heavy

      

      
Same drawing at 2.6 units. Strongest at 16 pixels, slightly clumsy at 64.

    

    

      
A5 · Tapered wing

      

      
The last stroke becomes a filled feather that tapers to a point. The wing finally has a tip.

    

    

      
A10 · Tapered, heavy recommended

      

      
Tapered wing on a 2.5-unit W. Reads as a letter in the tray and as a wing on the tile.

    

    

      
A6 · Double wing

      

      
Both outer strokes lift. Symmetric and bird-like, but it loses the single wing-tip idea.

    

    

      
A7 · Italic

      

      
Baseline skewed 12 degrees. Adds motion; the tray version leans a little.

    

    

      
A8 · Low and wide

      

      
Shorter W with a longer sweep. Calmer, a bit less distinctive.

    

  


Whichever you pick, the tray version inherits the taskbar foreground color like the built-in icons, and state lives in a small badge at the bottom-right corner because that survives being tiny.

13 · When an operation fails

  
The batch keeps going past a failure and the failed row stays red. Selecting it opens a diagnosis: winget's raw error, what it usually means, and the retry variants that fix the common causes. Wingman recognizes winget's error codes and the well-known MSI codes; anything else shows the last lines of the log.

  

  
  • Rretry as-is
  • Iretry interactive
  • Sretry skipping the hash check
  • Hhold at the current version
  • Eexclude from Wingman updates
  • lfull log






  
14 · Taking a self-updating app out of Wingman's hands

  
Discord, Spotify, Chrome, and the like update themselves, and winget's copy of their installer is often stale, so winget upgrade --all fails or reinstalls them every week. The update policy dialog, reached with p on any row or from the failure screen, offers four levels. Exclude is the one for these apps: the package stays in Installed with a marker, but leaves the Updates tab, the auto-update task, and the toast counts.

  

  
Afterwards the Updates tab shows a one-line footer for excluded packages so they never disappear silently. Each policy maps to storage you already have: hold is a blocking winget pin, skip-version is IgnoredVersion, and exclude is UpdatesIgnored, so all three survive a bundle export to UniGetUI and back.

  

  
  • popen update policy
  • eon Updates: show / hide excluded rows
  • Entersave
  • Esccancel
