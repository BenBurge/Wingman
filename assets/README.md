# Assets

Every icon and image in this folder, the `.ico` files and the `wingman.png`,
`wingman-logo.png`, and `social-preview.png` PNGs, is generated by
`tools/Make-Icons.ps1`. Do not edit them by hand; change the script and re-run
it instead. `social-preview.png` is uploaded by hand under the repository's
Settings → Social preview.

The SVGs in `screenshots/` are generated by the TUI harness (`dotnet run --project tools/TuiHarness -- 96 30 Midnight --svg assets/screenshots`); do not edit them by hand.
